# README.cm-chords.md

Правила для списков аккордных блоков `c`/`c1` (простые/сложные) композиции и семантика их редактирования.

## Списки

- `c` — простые аккордные блоки, `c1` — сложные (тяжёлые) аккордные блоки.
- Оба списка редактируются независимо друг от друга.

## Редактирование

- При каждой правке текстового блока композиции сначала выполняется `fillHardChords(com)`: смена аккордного блока в любом из режимов, вставка или удаление аккордного блока, а также вставка или удаление текстового блока.
- `fillHardChords` клонирует весь простой список в `c1` (deepClone) только когда `c1` равен null — проверка выполняется при каждой правке, ссылка на `c` никогда не подменяется.
- Страховка: если длины `c1` и `c` расходятся, недостающие записи каждого списка заполняются из другого через `||=` (в обе стороны), пока длины не сравняются.
- После каждой правки, когда списки полностью совпадают (`checkIsEq`), `com.c1` обнуляется, и сложный список снова следует за `c`.

## Бемоли

- Если в блоке аккордов есть бемольные аккорды (`Bb`, `Eb` и т. п.) и блок показан в блоке ошибок, рядом выводится кнопка `b->#`.
- Нажатие заменяет все бемольные аккорды этого блока на диезные эквиваленты (`Bb` → `A#`) и сохраняет блок в том же состоянии, которое редактирует редактор блока.
- В форме создания песни сложные аккорды (категория `complexChords`, обёрнутые в `{...}`) показываются как предупреждения и не блокируют кнопку создания песни; блокируют только реально неверные аккорды (категория `incorrectChords`, обёрнутые в `[...]`).

## Умный поиск

- `BackLocaleKey.CmSmartSearchChordsMismatch` (**Количество аккордов не равно аппликатуре**): _ком отбирается, если у какого-либо его орда есть индекс блока `c` и позиции аппликатуры `p`, а в блоке `c[ord.c]` хотя бы в одной строке, кроме последней, число аккордов (непустые фрагменты `line.trim().split(' ')`) не равно числу позиций `ord.p[linei]`; пустые строки пропускаются._
- `BackLocaleKey.CmSmartSearchUnknownChords` (**С неизвестными аккордами**): _собирает аккорды из `transposedBlocks()`, разбивая каждый блок по `/[\s.-]+/`, вычитает известные аккорды — ключи `chordPackFileStore`; ком отбирается, если разница непуста, а при ошибке разбора ком пропускается._
- Оба фильтра выполняются на сервере: ветки `getSmartSearchComws_1` вызывают `takeChordsMismatchComws` / `takeUnknownChordsComws` из `src/back/apps/cm/smart-search/*`.
