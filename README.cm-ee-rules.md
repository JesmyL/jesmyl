# README.cm-ee-rules.md

Правила проверки ё/е в редакторе песен.

## Хранение словаря

- Единственный источник правил ё/е — бэкенд (`eePackFileStore`, файл `/apps/cm/eeStorage.json`).
- На фронте словарь не хранится и не кэшируется в IndexedDB.
- `editedEEWords` остаётся шиной обновлений: пришедшие слова складываются только в память (`sharedEeWordsAtom`) для обновления уже загруженного среза страницы правил.

## Проверка текста

- Фронт отправляет массив текстов блоков на бэкенд одним вызовом `checkTextEe` (дебаунс 500 мс); ответ — массив ошибок по позициям блоков.
- Локально на фронте остаются только проверки недопустимых символов и парности кавычек/скобок.
- Результаты проверок объединяются: ошибки длины строки и локальные ошибки имеют приоритет, иначе показываются ошибки ё/е с бэкенда.
- Для каждого слова с ошибкой ё/е показывается кнопка с исправленным вариантом; нажатие заменяет только это вхождение слова в тексте блока.
- Перед такой заменой старое значение блока добавляется в буфер предыдущих текстов редактора (тот же, что используется обычными правками блоков).

## Страница правил

- Страница `EERulesPage` не получает весь словарь: слова и их коды запрашиваются с бэкенда срезами (`getEEWords`) и поиском (`searchEEWords`).
- Список слов-кандидатов строится из локальных текстов песен; сохранение изменённых слов идёт прежним методом `setEEWords`.
